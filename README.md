# Ringkeep website

The website for Ringkeep, a private iPhone app for SMART_RING smart rings. Served by GitHub Pages at https://bflynn71.github.io/ringkeep/

- `index.html`: main page
- `privacy/`: privacy policy (linked from the app and App Store Connect)
- `support/`: support page
- `assets/site.js`: the support email is set once here
